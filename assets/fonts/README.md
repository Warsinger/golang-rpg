# Press Start 2P

The owner selected Press Start 2P in issue #6 after comparing the legacy Arcade,
Press Start 2P, Terminus TTF and M+ 1p fonts. Native and browser builds embed the
same unmodified font, rendered at 8 logical pixels with existing line spacing.
