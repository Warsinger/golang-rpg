# Arcade font

`arcade_n.ttf` contains the unchanged `ArcadeN_ttf` bytes previously imported from Ebitengine v1.12.12 (`examples/resources/fonts/arcaden.go`). Keeping this resource locally removes the legacy engine dependency without changing the game typography.

The font is by Yuji Adachi. Its original notice and restrictions are reproduced in [UPSTREAM-LICENSE.md](UPSTREAM-LICENSE.md), under `arcade_n.ttf`. That upstream file also contains a separate notice for the unrelated M+ font; M+ is not bundled here. No additional rights to this font are granted by this repository.
